用户卡片位于主窗口的**左下角**，显示：
- **头像图片**：`:/Resource/Image/avatar.png`
- **标题**：Prism Manager
- **副标题**：v1.0.0 - 国腾天创

---

## 🖼️ 更换头像步骤

### 方法 1：替换默认头像（推荐）

1. **准备头像图片**
   - 格式：PNG（推荐，支持透明背景）
   - 尺寸：**64x64** 或 **128x128** 像素
   - 文件名：`avatar.png`

2. **放置图片**
   ```
   D:\Code\Prism-Manager\assets\Image\avatar.png
   ```

3. **重新编译项目**
   - 在 Visual Studio 或 CLion 中重新构建项目
   - 或使用命令：
     ```bash
     cmake --build build --config Debug
     ```

4. **运行程序查看效果**

---

### 方法 2：使用其他图片路径

如果你想使用项目外部的图片（不嵌入资源文件）：

1. **修改代码**（`src/ui/MainWindow.cpp:106`）
   ```cpp
   // 从文件系统加载头像
   setUserInfoCardPixmap(QPixmap("C:/Users/YourName/Pictures/avatar.png"));
   ```

2. **使用相对路径**
   ```cpp
   // 从程序运行目录加载
   setUserInfoCardPixmap(QPixmap("./avatar.png"));
   ```

---

## 🎨 头像设计建议

### 推荐尺寸
- **最小**：64x64 像素
- **推荐**：128x128 像素
- **最大**：256x256 像素

### 样式建议
- ✅ 使用**圆形**或**圆角**头像效果更佳
- ✅ 背景透明（PNG 格式）
- ✅ 简洁、对比度高的图案
- ❌ 避免过于复杂的图片
- ❌ 避免文件过大（建议 < 100KB）

### 在线工具推荐
- [TinyPNG](https://tinypng.com/) - 压缩 PNG 图片
- [Squoosh](https://squoosh.app/) - 图片优化工具
- [Remove.bg](https://www.remove.bg/) - 去除背景

## 🐛 常见问题

### Q1: 头像不显示怎么办？

**可能原因**：
1. 图片路径错误
2. 图片文件不存在
3. 资源文件未正确编译

**解决方法**：
```cpp
// 添加调试代码到 MainWindow.cpp:106
QPixmap avatar(":/Resource/Image/avatar.png");
if (avatar.isNull()) {
    qDebug() << "头像加载失败！";
} else {
    qDebug() << "头像加载成功，尺寸：" << avatar.size();
    setUserInfoCardPixmap(avatar);
}
```

### Q2: 头像显示模糊？

**原因**：图片尺寸过小或过大

**解决方法**：
- 使用 **128x128** 像素的图片
- 确保图片质量良好

### Q3: 重新编译后头像没变化？

**解决方法**：
1. 清理构建目录：`cmake --build build --target clean`
2. 重新构建：`cmake --build build --config Debug`
3. 确认图片已正确放置在 `assets/Image/` 目录
