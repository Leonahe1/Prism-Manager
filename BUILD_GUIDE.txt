================================================================================
  Prism Manager - Quick Build Guide
================================================================================

项目名称: Prism (仿真配置集成环境)
版本: 1.0.0
技术栈: C++17, Qt 5.14+, CMake 3.15+

================================================================================
  1. 前置要求
================================================================================

- Windows: Visual Studio 2019 + Qt 5.14.2
- Linux: GCC 7+ + Qt 5.14.2
- CMake 3.15+

================================================================================
  2. 安装第三方库
================================================================================

请按照以下步骤安装依赖库：

cd 3rdparty
git clone https://github.com/Liniyous/ElaWidgetTools.git
git clone https://github.com/jbeder/yaml-cpp.git
cd ..

详细说明请查看: 3rdparty/README.txt

================================================================================
  3. 构建项目
================================================================================

### Windows (Visual Studio)

mkdir build
cd build
cmake .. -G "Visual Studio 16 2019" -A x64
cmake --build . --config Release

### Linux

mkdir build
cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j4

================================================================================
  4. 运行程序
================================================================================

构建完成后，可执行文件位于:

Windows: build/bin/Release/Prism.exe
Linux:   build/bin/Prism

运行示例:

cd build/bin
./Prism  (Linux)
Prism.exe  (Windows)

================================================================================
  6. 核心功能
================================================================================

✓ 多格式配置解析 (INI, JSON, YAML)
✓ 自定义后缀映射 (.gttc -> INI)
✓ 进程运行和日志监控
✓ 实时编码转换 (GBK -> UTF-8)
✓ 项目管理和状态监控
✓ Fluent Design UI (通过 ElaWidgetTools)

================================================================================
  7. 使用说明
================================================================================

1. 创建新项目:
   - 菜单: File -> New Project
   - 选择配置文件 (.ini, .json, .yaml)

2. 运行项目:
   - 选择项目后点击 Run 按钮或按 F5

3. 查看日志:
   - 底部日志面板实时显示进程输出

4. 自定义格式映射:
   - 在代码中使用 ParserFactory::registerCustomExtension()
   - 示例: factory.registerCustomExtension("gttc", ConfigFormat::INI);

================================================================================
  8. 故障排除
================================================================================

Q: CMake 找不到 Qt5
A: 设置 CMAKE_PREFIX_PATH 环境变量指向 Qt 安装目录
   例: set CMAKE_PREFIX_PATH=C:\Qt\5.14.2\msvc2017_64

Q: 链接错误: undefined reference to ElaWidgetTools
A: 确保已正确克隆 ElaWidgetTools 到 3rdparty/ 目录

Q: 中文乱码
A: ProcessRunner 已自动处理 Windows GBK 编码转换
