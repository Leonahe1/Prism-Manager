# 图片资源说明

## 文件说明

### avatar.png
- **用途**: 用户卡片头像（左下角）
- **推荐尺寸**: 64x64 像素或 128x128 像素
- **格式**: PNG（支持透明背景）
- **位置**: `assets/Image/avatar.png`

### icon.png
- **用途**: 应用程序窗口图标
- **推荐尺寸**: 256x256 像素或 512x512 像素
- **格式**: PNG（支持透明背景）
- **位置**: `assets/Image/icon.png`

## 如何替换头像

1. 准备你的头像图片（PNG 格式，推荐 64x64 或 128x128 像素）
2. 将图片重命名为 `avatar.png`
3. 将图片复制到此目录（`assets/Image/avatar.png`）
4. 重新编译项目即可生效

## 注意事项

- 建议使用 PNG 格式，支持透明背景
- 图片不宜过大，避免影响程序启动速度
- 可以使用圆形头像效果更佳
